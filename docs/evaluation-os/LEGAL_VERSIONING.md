# Legal Versioning

Legal source records carry source ID, version, effective dates, official citation, verification source, and lifecycle status. A `LegalVersion` must be registered before a control can be registered.

Supported source families include the existing authoritative catalog entries for the Constitution of Kenya Article 227, PPADA 2015, PPADR 2020, PPRA instruments, and standard tender documents where an official version is available.

When the official text, applicability, or effective date is uncertain, the record must use `REQUIRES_LEGAL_REVIEW`; the runtime must not silently activate it.
