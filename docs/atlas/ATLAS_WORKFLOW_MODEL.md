# Atlas Workflow Model

`ATLAS-PSN-WF-001`: Project Supply Nexus currently exposes read contracts only.
Requirement approval, allocation, escalation, recovery and site coordination
remain human-gated workflow definitions to be enacted after authoritative
project and milestone sources are available.

`ATLAS-NPI-WF-001`: procurement award, supplier selection, contract, budget,
and regulated decisions remain human-gated; Phase 05 adds no autonomous write
workflow.
