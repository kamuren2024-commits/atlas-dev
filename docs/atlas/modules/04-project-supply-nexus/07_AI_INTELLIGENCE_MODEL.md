# AI Intelligence Model

The existing Project Supply Agent remains registered in the Agent OS, but its
readiness scorer now returns `UNAVAILABLE` when no governed requirement and
logistics evidence is supplied. It no longer returns a fabricated percentage.

Future Project Supply Analyst, Gap Investigator, Delivery Risk Analyst,
Milestone Dependency Analyst, Recovery Planner and Copilot tools must call
authorized PSN contracts and label outputs FACT, DERIVED, INFERENCE, SCENARIO,
UNKNOWN or UNAVAILABLE. No PSN AI tool was claimed as implemented.

Change ID: `ATLAS-PSN-AI-001`.
