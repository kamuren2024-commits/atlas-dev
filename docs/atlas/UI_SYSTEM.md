# Atlas Enterprise UI System

The reusable Atlas primitives live in `src/components/ui/atlas`: page headers, panels, KPI cards, AI insight cards, status badges, empty states, and error states. `AtlasModuleWorkspace` composes these primitives into a graph-aware module with loading, error, empty, evidence, intelligence, and approval-gated action states.

The production Command Center is not redesigned by this phase.
