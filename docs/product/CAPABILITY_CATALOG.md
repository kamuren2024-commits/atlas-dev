# SYSTEM CAPABILITY CATALOG

This document lists all active system capabilities, their associated user roles, and execution environments.

---

## 1. System Capabilities Directory

Our platform supports four core capability classifications:

* **Procurement Scribe**: Translates public requisitions into structured bid formats. (Clearance: SCM Officers).
* **Compliance Auditor**: Scans bid draft formats against governing regulations. (Clearance: Compliance Officers).
* **Grid Twin Simulator**: Predicts transformer lifetimes and models fault failures. (Clearance: SRE Engineers).
* **On-Call Alerts Gate**: Dispatches high-severity alerts to support personnel. (Clearance: SRE Leads).
