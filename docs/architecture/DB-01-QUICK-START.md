## ROLLBACK PROCEDURE (Emergency Only)

```
IF PostgreSQL fails:

1. Stop application
   $ systemctl stop atlas
   
2. Revert DatabaseCore to SQLite
   $ git revert <prisma-commit>
   
3. Verify SQLite intact
   $ sqlite3 data/salience_atlas.db ".tables"
   
4. Restart application
   $ systemctl start atlas
   
5. Verify data present
   $ curl http://localhost:3000/api/health
   
6. Report issue
   $ Create incident report with evidence
```

**Time to Rollback:** <5 minutes  
**Data Loss Risk:** Zero (SQLite kept intact)  
**Service Downtime:** <10 minutes
