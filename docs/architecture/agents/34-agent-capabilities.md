# 34. Agent Capabilities Framework
## Salience Atlas v5

Capabilities represent the composable actions that an Enterprise Agent is certified to perform. They are registered in the `CapabilityRegistry` and loaded dynamically during agent assembly.

### Core Capabilities List
- **PLANNING**: Formulates hierarchical step structures and dynamic workflow graphs.
- **ANALYSIS**: Inspects complex datasets and outputs numeric recommendations or strategic scores.
- **RETRIEVAL**: Accesses structured regulatory systems and databases to fetch relevant text clauses.
- **VALIDATION**: Structural validation, contract validation, and data formatting.
- **GENERATION**: Synthesizes formal drafts or documents.
- **COMPLIANCE**: Verifies legal validity against acts like Kenya PPADA 2015.
- **MONITORING**: Inspects metrics to trigger system alerts.
- **NOTIFICATION**: Sends alert summaries to webhooks and users.
