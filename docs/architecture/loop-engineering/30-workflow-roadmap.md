# 30. Workflow to Multi-Agent Orchestration Roadmap
## Salience Atlas v5

This roadmap outlines how subsequent development phases will leverage the stable `WorkflowOrchestrator` substrate to introduce autonomous multi-agent cooperation.

### Migration Milestones

```
  [ Phase 3: EWO Substrate ]  <-- (We are here: stable DAG execution, adapters)
              │
              ▼
  [ Phase 4: Agent Registry ]  <-- (Register cognitive capabilities, team nodes)
              │
              ▼
  [ Phase 5: Multi-Agent Teams ] <-- (Collaborative planning, cross-node negotiation)
              │
              ▼
  [ Phase 6: Knowledge Graphs ] <-- (Cognitive memory linkage, semantic rules context)
```

### Key Milestones
1. **Milestone 1**: Register cognitive agents as executable `WorkflowNode` types.
2. **Milestone 2**: Implement dynamic sub-graph generation using LLM/Gemini routing instead of static conditional routing.
3. **Milestone 3**: Bridge multi-agent negotiation logs directly into the history manager audit trail.
