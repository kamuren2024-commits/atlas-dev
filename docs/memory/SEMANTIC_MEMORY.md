## 2. Semantic Graph Queries

* **Transitive Dependency Resolution**: Determines downstream grid hazards of failed equipment.
* **Affiliation Scans**: Uncovers supplier collusions by evaluating shared properties and corporate registries.
* **Policy Compliance Queries**: Maps current bids to governing sections of the PPADA-2015 code.
