# METADATA OWNERSHIP MODEL

This document maps data assets and glossary terms to specific teams and individuals.

---

## 1. Stewardship Matrix

We enforce clear data ownership to streamline issue resolution and data access requests:

```
  [ Data Product / Term ] ──► [ Appointed Steward ] ──► [ Review SLA (Response in Hours) ]
                                                            - Grid Twin: Lead Planner (2 hrs)
                                                            - Audits: Chief Compliance (4 hrs)
```

---

## 2. Escalation Rules

If data quality drops below target thresholds, ownership routing tables escalate notifications to the appropriate Director for remediation.
