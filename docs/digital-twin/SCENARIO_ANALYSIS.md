# SCENARIO ANALYSIS PLAYBOOKS

This document details standardized What-If scenario playbooks for managing national infrastructure supply constraints.

---

## 1. Scenario Registry

### Playbook A: East African Border Closures (`sc_ea_border`)
* **Risk Class**: Geopolitical Disruption
* **Trigger condition**: Custom border checkpoint delay alerts exceed 7 days.
* **Mitigation strategy**: Re-route incoming shipments via alternative shipping ports (e.g. Dar es Salaam).

### Playbook B: Transformer Coolant Shortages (`sc_transformer_coolant`)
* **Risk Class**: Supply-Chain Exhaustion
* **Trigger condition**: Global coolant supplier reserves drop below 20%.
* **Mitigation strategy**: Substitute materials immediately with verified local partners.
