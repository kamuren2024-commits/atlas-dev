                        INTEGRATION GUIDE
================================================================================

1. IMPORT & INITIALIZE:
   ```typescript
   import { initializeCompleteEventFabric } 
     from './backend/integration/event-init';
   
   const { eventFabric, integration } = 
     await initializeCompleteEventFabric(httpServer);
   ```

2. SUBSCRIBE TO EVENTS:
   ```typescript
   eventFabric.subscribe(
     { severity: ['CRITICAL'] },
     async (event) => {
       // Handle critical events
     }
   );
   ```

3. PUBLISH EVENTS:
   ```typescript
   await eventFabric.publishTelemetry('SCADA', telemetryData);
   await eventFabric.publishGridEvent('SCADA', eventData);
   ```

4. QUERY STATE:
   ```typescript
   const state = eventFabric.getState();
   const stats = eventFabric.getStatistics();
   ```

5. EXPRESS MIDDLEWARE:
   ```typescript
   import createEventApiRouter 
     from './backend/event-fabric/event-api-routes';
   app.use('/api/events', createEventApiRouter());
   ```

6. SHUTDOWN:
   ```typescript
   await shutdownEventFabric();
   ```
