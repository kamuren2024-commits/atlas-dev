# AI GOVERNANCE SYSTEM — KETRACO SCM Intelligence Nexus

This framework outlines the policies, guardrails, routing mechanics, and cost limits that govern AI model usage, agent actions, and provider interactions within the KETRACO SCM Intelligence Nexus.

---

## 1. Registered Provider Catalog & Routing Logic

The system maintains a registry of approved enterprise AI providers. Only models defined in the official catalog are permitted to receive prompts.

```
                  [ API Request Received ]
                             │
                             ▼
               [ Cost Governance Gatekeeper ]
            (Checks: Daily/Monthly Budgets, RPS)
                             │
                  ┌──────────┴──────────┐
          [ Within Limits? ]     [ Limits Exceeded? ]
                  │                     │
                  ▼                     ▼
        [ Fallback Chain Lookup ]   [ HTTP 429 Blocked ]
      (e.g., Gemini -> Groq -> OpenAI)
                  │
                  ▼
        [ KeysVault Key Query ]
                  │
        ┌─────────┴─────────┐
    [ Key Active? ]     [ Key Throttled? ]
        │                   │
        ▼                   ▼
  [ Execute prompt ]   [ rotateKey() ]
```

### Fallback Prioritization (Priority Order)
1. **Google Gemini (Default)**: Priority 1 — Primary model for procurement bids and contract analysis due to context length, safety profiles, and cost efficiency.
2. **Groq Cloud**: Priority 2 — Utilized for fast extraction of tabular data from invoice bids.
3. **OpenRouter**: Priority 3 — Dynamic fallback route to access DeepSeek models.
4. **Cerebras AI / OpenAI / Anthropic**: Priority 4, 5, 6 — Standard auxiliary routes.

## 2. Hard Cost Controls & Rate Limits

Operational overhead is protected through the following environmental thresholds managed inside `/backend/ai-federation/config/provider-config.ts`:

* **`AI_MONTHLY_BUDGET_USD` (Default: `$100.00`)**: Absolute monthly spend boundary. Once reached, all AI queries are routed to an offline dummy handler or rejected until reset.
* **`AI_DAILY_BUDGET_USD` (Default: `$10.00`)**: Prevents "infinite loop" budget drainage. Restricts cumulative daily model spends.
* **`AI_REQUEST_LIMIT_PER_MINUTE` (Default: `500`)**: Protects model rate limits and prevents DoS attempts by rate-limiting client connections.
* **`AI_MAX_AGENT_DEPTH` (Default: `20`)**: Restricts recursive multi-agent loops during SCM contract risk audits to prevent agent runaways.

---

## 3. Prompt Safety & Guardrails

To ensure operational compliance and protect national energy infrastructure data:
* **Bounded Context Instruction**: All system prompts are pre-pended with strict context guidelines. Agents are explicitly forbidden from answering questions outside of SCM, power grid logistics, contract auditing, or KETRACO grid engineering.
* **Sensitive Pattern Redaction**: Prompts are scanned before submission. Any direct reference to critical security codes, raw keys, or operational passwords is auto-redacted and flagged.
* **Structure Outputs**: Models are forced to emit structured JSON complying with TypeScript interfaces to eliminate parsing crashes and downstream data corruption.

---

## 4. Human-in-the-Loop Governance

* **Advisory Status**: Recommendations generated by the Procurement or Bid Audit Agents are labeled as **Advisory Only**.
* **Review Gatechecks**: Any modification to contract scores, supplier ratings, or route risk metrics requires explicit human confirmation via the dashboard before saving to the database.
* **Traceable Decisions**: Every AI recommendation outputs its reasoning, the source files scanned, the exact model version used, and a direct citation of the contract clauses analyzed.
